# Genuine application screenshots / Captures authentiques

This folder is only for **screenshots of the actual running OrbitStore macOS application**. No fabricated app screenshots, AI-generated interface renders or marketing mockups.

Suggested names:
- discover.png: Discover page / Découvrir
- ecosystems.png: Ecosystems / Écosystèmes
- search.png: Real GitHub search / Recherche GitHub réelle

A GitHub Actions macOS screenshot workflow may attempt these captures. GUI capture on hosted runners can fail because of display or Screen Recording permissions. Never replace a failed capture with a mockup.

**Manual method:** Run OrbitStore on your Mac, open each page, and press Shift–Command–4 followed by Space, then click the OrbitStore window. Save the genuine PNGs here. Do not expose private app lists, passwords, Finder paths or personal data. Send them by Pull Request.

**FR :** Captures réalisées sur le véritable logiciel, sans données privées. En cas d'échec de GitHub Actions, utilisez l'outil Capture d'écran de macOS et ajoutez les images dans ce dossier.

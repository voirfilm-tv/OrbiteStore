# Privacy / Confidentialité

This documents the reviewed **v0.5.0 source**, not an independent audit.

### On-device

OrbitStore reads app bundles from /Applications, ~/Applications and /System/Applications to display names, versions, bundle IDs and paths. Local settings and limited repository caches use UserDefaults. The app periodically rescans while running.

### External requests

- Search terms and repository lookups go to the **GitHub API**.
- Project README and image files may be fetched from GitHub or official websites.
- The Obsidian and Jellyfin registries provide plugin metadata.
- Enabling extension notifications can cause queries containing the **name of a newly installed app**.
- Opening an installed application's detail page can cause a GitHub search for extensions, including for proprietary apps.
- Network providers may receive technical request metadata (e.g. IP address).

The reviewed application source does not contain a first-party analytics backend, advertising SDK or OrbitStore user account feature. These statements do not cover third-party network logging or future versions.

### Controls / Contrôles

Disable extension notifications in Preferences. Quit OrbitStore to stop periodic inventory scans. Search queries are transmitted to GitHub. No special macOS privileges should be requested for simple discovery.

**FR :** Les applications installées sont analysées localement, mais leur nom peut être envoyé à GitHub lors d'une recherche d'extensions. Les notifications sont facultatives. Quitter OrbitStore interrompt les analyses périodiques.

### Installed app discovery as of v0.2.2

In addition to standard Applications directories, OrbitStore also reads app bundle URLs from macOS running applications, its own bundle, and LaunchServices' registered OrbitStore bundle identifier. The inventory is local, but an installed app name may be submitted to GitHub when the user requests extension discovery or has enabled related notifications. OrbitStore does not require Screen Recording or Full Disk Access for these checks.

**FR :** La recherche d'applications s'étend aux logiciels actuellement ouverts et à l'identifiant macOS d'OrbitStore ; une application simplement ouverte depuis un DMG monté n'est pas considérée comme installée.

### Lifecycle features added in v0.3.0 / Gestion des logiciels

- OrbitStore stores a local operation log (up to 250 entries), install receipts (repository, bundle ID, signing Team ID, install path and date), local preferences and a copy of the previous .app bundle when replacing it.
- Default locations: `~/Library/Application Support/OrbitStore/history.json`, `receipts.json` and `Backups/`. Downloaded packages use `~/Downloads/OrbitStore/` unless cleaned after installation.
- Archive unpacking and code-signature checks run locally. No proprietary installed-app list is uploaded to an OrbitStore server.
- Source lookup can query Homebrew Cask API; user-initiated Obsidian plugin installation accesses the upstream release and writes into a user-selected Obsidian vault.
- Daily update digest is opt-in, only while the app is open; notification preferences are stored locally.

**FR :** L'historique, les reçus d'installation et les sauvegardes des anciennes applications sont locaux. Les extensions Obsidian peuvent exécuter du JavaScript ; le coffre est choisi manuellement, l'activation n'est jamais automatique.

### Public index introduced in v0.3.1

OrbitStore downloads a single static, public GitHub JSON index of macOS release metadata. The index is generated by GitHub Actions rather than indexing local software or sending an installed-app list to a backend. The fetched catalog is cached in local Application Support. Direct GitHub search still transmits the user's query to GitHub when used.

### Catalog and updater options (v0.4.0)

Developer Mode is stored locally in UserDefaults. In consumer mode, search matches the locally downloaded GitHub index rather than submitting every search term to GitHub. Developer Mode enables live GitHub repository search, which transmits typed queries. The dedicated OrbitStore updater checks the project's GitHub releases and saves a user-requested DMG under Downloads/OrbitStore, verifying its checksum before opening Finder. No silent self-installation occurs.
### Faster icons and storefront collections (v0.5.0)

Icons downloaded from upstream GitHub READMEs and known official homepages are cached under ~/Library/Caches/OrbitStore/AppIcons. The app bounds parallel icon requests to four and remembers absent icons temporarily. The editorial alternatives and self-hosted collections are stored locally in source code, not personalized through tracking or a new API. Opening a self-hosted project uses the browser to visit its public GitHub page. The update check's per-app recent timestamps are stored in UserDefaults to avoid rate-limit pressure.

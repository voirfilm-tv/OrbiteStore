# Code of Conduct / Règles de conduite

OrbitStore welcomes developers of all skill levels, backgrounds and experience.

**Be constructive.** Focus criticism on code and decisions, not people. Be patient with new contributors, give attribution, and document technical claims.

**Not acceptable:** threats, harassment, discrimination, doxxing, malicious Pull Requests, spam, backdoors, or public disclosure of sensitive personal information.

Maintainers may remove content, close discussions, or restrict participation to protect the community. Please report security vulnerabilities through [SECURITY.md](SECURITY.md); never disclose exploit information in public Issues.

**FR :** Respect, entraide et critiques techniques argumentées. Harcèlement, discrimination, divulgation de données privées, spam et contributions malveillantes sont interdits. Les responsables du dépôt peuvent modérer les échanges.
